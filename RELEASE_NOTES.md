# Release Notes

Version v1.4.1 — October 20, 2026

## Favorite games
Right-click any game on the home screen to add it to your favorites. Favorites get their own section at the top of the game list, marked with a star, and come first in the titlebar's game menu. The same right-click menu also lets you open a game, or set its folder if HML couldn't find it.

## Right-click menus
Text fields now have a right-click menu with Cut, Copy, Paste and Select all, styled to match the rest of HML. Right-clicking selected text elsewhere in the app offers Copy.

## Getting home
Click the HML logo in the titlebar to go back to the home screen from any game. The "Back to previous game" button on the home screen is gone, along with its Esc shortcut.
