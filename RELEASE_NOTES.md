# Release Notes

Version v1.1.6 — October 17, 2026

## Unreal games with Shimloader
RV There Yet, Palworld, Astroneer and the other Shimloader games on Thunderstore are now supported. Install a mod and HML pulls in Shimloader for you, then Start modded loads your profile's mods into the game.

NOTE: If you already installed UE4SS by hand, Start modded moves your copy aside and Start vanilla puts it back.

## No more duplicate games
- RV There Yet no longer shows up twice when you added it yourself. HML's own entry wins now that it can mod the game.
- Nexus Mods pages now match games even when the names differ by punctuation, like "RV There Yet" vs "RV There Yet?".

## Fixes
- Games Thunderstore doesn't list a Steam ID for now pick it up from your Steam install, so they get their banner and launch through Steam.
